# AeroCalc

Android-приложение для вычислений, изучения физики, химии и геометрии. Kotlin, Jetpack Compose; Android 7.0 / API 24 и выше.

## Возможности

- Научный калькулятор: история, объяснение решения, PDF, камера с подтверждением распознанного выражения.
- Алгебра без интернета: упрощение и производная многочленов до степени 12, линейные и квадратные уравнения с точными дробями и явно обозначенными приближениями. Поддерживаемая грамматика указана в интерфейсе.
- Графики: обычный, полярный и параметрический режимы, параметры функций, таблица, библиотека примеров и численный анализ.
- Физика: формулы, учебный тренажёр, маятник, баллистика, опыт F = ma; запись акселерометра/линейного ускорения в CSV. Датчики зависят от устройства, запись останавливается при выходе с экрана или из приложения.
- Геометрия: формулы с шагами, вращаемые 3D-фигуры, координатные построения точек, отрезков и окружностей с локальным черновиком.
- Химия: молярная масса, балансировка реакций, 118 элементов, модель атома, справочная таблица растворимости, редактор нейтральных структур C/H/O/N и экспорт MOL V2000. Проверка валентности не доказывает устойчивость вещества. Непроверенные клетки растворимости обозначены `?`.
- Конвертер: десятичные расчёты, 10 категорий, абсолютная температура и разность температур.
- Обучение: 24 вопроса по 6 темам, задание дня, объяснения, сохранённые попытки и повторение ошибок; прежние короткие уроки сохранены.

## Дизайн

Тёмное стекло по пользовательским референсам: единый фон, прозрачные поверхности, резкий текст, мягкое движение навигации и системная тактильность. Android 13+ поддерживает краевое преломление, Android 12 — размытие; на старых устройствах применяется прозрачный вариант без шейдера. Это собственная реализация Compose. Ощущение вибрации и плавность проверяются на физическом телефоне.

Разделы науки открываются каталогами карточек. Формы, результаты и объяснения прокручиваются и учитывают увеличенный шрифт.

## Сборка и проверки

Нужны Android SDK 36, JDK 21 для Gradle и установленный JDK 17 для toolchain модулей.

```powershell
$env:JAVA_HOME = 'C:/Program Files/Java/jdk-21'
./gradlew.bat :app:assembleDebug :app:lintDebug --offline
./audit/run-unit-tests.ps1 :app:testDebugUnitTest :feature-graphing:testDebugUnitTest --console=plain
./gradlew.bat :app:connectedDebugAndroidTest --offline
```

Скрипт JVM-тестов использует временный ASCII-junction: на Windows worker Gradle не загружает тестовые классы из кириллического пути проекта.

APK: `app/build/outputs/apk/debug/app-debug.apk`.
AAB: `app/build/outputs/bundle/release/app-release.aab`.

## Реклама и выпуск

Debug использует официальные тестовые блоки AdMob. Release читает идентификаторы и параметры подписи из локальных Gradle properties; ключи, пароли, APK и AAB исключены из Git. При отсутствии production ID межстраничного блока этот формат в release отключён.

Баннер размещается в каталоге, обучении и истории. Межстраничное объявление возможно после новых завершённых учебных заданий с паузой и ограничением частоты. Повтор пройденного задания и одно только время в приложении его не вызывают. UMP управляет согласием; для младше 13 лет реклама отключена, для 13–17 настроена возрастная обработка.

Перед Google Play нужны подтверждённые максимальный versionCode, активация нового ключа загрузки и соответствующие фактической сборке сведения об аудитории/рекламе/данных. Публичный сертификат нового ключа: `audit/upload_certificate.pem`. Закрытый ключ хранится вне репозитория.
