## 🌟 Главная концепция и цель проекта

**Идея:** Заменить десятки разрозненных приложений (отдельный калькулятор, формульник по физике, таблица Менделеева, 3D-решатель геометрии, графопостроитель) **единым цельным экосистемным продуктом**, в котором студент, инженер или школьник может решить любую задачу за 1–2 тапа.

### 🎯 Ключевые принципы продукта:
* **Zero-Scroll UX:** Весь ключевой контент и клавиатура помещаются на один экран смартфона без необходимости бесконечной прокрутки.
* **Instant Presets (1 тап):** Готовые жизненные сценарии (разгон авто, энергия свободного падения, молярная масса $H_2SO_4$, закон Ома) для мгновенного получения результата.
* **Глубокая визуализация:** Интерактивные симуляторы (маятник, баллистика), вращаемые пальцем 3D-стереометрические фигуры, электронные оболочки атома Бора, графики с автоматическим поиском корней и экстремумов.
* **Export & Education:** Пошаговые решения с возможностью мгновенного экспорта в красиво оформленный PDF-документ.

## 🎨 Философия дизайна и UX (Titanium Minimalist)

Приложение спроектировано по дизайн-стандартам **Obsidian Dark & Bento Grid 2.0**:

* **Палитра:**
  * Фон: глубокий матовый черный `#08090C` (экономит заряд батареи на OLED).
  * Карточки: графитовый сланец `#12141C` и `#1A1D27` с тонкой каймой `#262936`.
  * Акценты: чистый титановый белый `#FFFFFF`, неоновый голубой `#38BDF8` (границы и бейджи СИ), изумрудный `#10B981` (успех) и рубиновый `#EF4444` (ошибки/очистка).
* **Типографика:**
  * Интерфейс: **Inter** (чистый, легко читаемый шрифт).
  * Числа и формулы: **JetBrains Mono** с включенными табличными цифрами (`tnum` / monospaced).
* **Kinetic Juice (Тактильность):**
  * Каждая кнопка клавиатуры и карточка имеет пружинный отклик `bounceClick` (`scale: 0.90 -> 1.0`).
  * Адаптивный Haptic Feedback (виброотклик) + щелчок при нажатии клавиш.
  * Плавные каскадные анимации появления списков и переходов.

## 🔬 Обзор модулей и функционала

### 1. 🧮 `feature-calculator` (Инженерный калькулятор)
* **Клавиатура:** Двухуровневая кастомная клавиатура `MathKeyboard` с тригонометрией, степенями, факториалами и логарифмами.
* **OCR-сканер:** Сканирование математических выражений камерой смартфона.
* **Шаги решения:** Нажатие на результат открывает Bottom Sheet с подробным пошаговым разбором.
* **PDF-экспорт:** Генерация официального PDF-документа с решением в 1 клик.
* **DEG/RAD:** Мгновенный переключатель угловых мер.

### 2. ⚡ `feature-physics` (Физика и симуляторы)
* **7 Жизненных пресетов:** Разгон авто, падение тела, торможение, плотность воды, закон Ома, энергия бега, работа силы.
* **Каталог формул:** Поиск по разделам (кинематика, динамика, термодинамика, электричество) с выбором любой искомой переменной.
* **Интерактивные симуляторы:** 
  * Математический маятник с динамическим графиком фазовой траектории.
  * Баллистическое движение снаряда под углом к горизонту.
* **Физический квиз:** Тестирование знаний формул.

### 3. 🧪 `feature-chemistry` (Химическая лаборатория)
* **Молярная масса:** Расчет массы любого сложного вещества (например, $H_2SO_4$, $K_2Cr_2O_7$) с разбивкой по элементам и цветными процентными долями.
* **Балансировщик реакций:** Автоматическая расстановка стехиометрических коэффициентов ($Fe + O_2 \rightarrow Fe_2O_3$).
* **Таблица Менделеева:** Интерактивная периодическая система с карточками свойств элементов.
* **Таблица растворимости:** Матрица растворимости кислот, солей и оснований в воде.
* **3D Модель Атома:** Анимированные электронные оболочки Бора на Compose Canvas.

### 4. 📐 `feature-geometry` (2D геометрия и 3D стереометрия)
* **2D Фигуры:** Треугольники, круги, трапеции, многоугольники с расчетом площадей, периметров, радиусов.
* **3D Стереометрия:** Куб, призма, пирамида, цилиндр, конус, сфера.
* **Интерактивный 3D Canvas:** Вращение 3D-тел пальцем (Pitch/Yaw), авто-ротация и голографическая координатная сетка пола с эффектом глубины.

### 5. 📈 `feature-graphing` (Графики функций)
* Построение 2D графиков функций $y = f(x)$, полярных и параметрических кривых.
* Автоматический анализ ключевых точек: корни ($f(x)=0$), локальные минимумы и максимумы, точки перегиба.
* Жестовое масштабирование (Pinch-to-zoom) и панорамирование.

### 6. 🔄 `feature-converter` (Конвертер величин)
* Перевод единиц: Длина, Масса, Температура, Площадь, Объем, Скорость, Давление, Энергия.
* Bento-карточки с интерактивной пружинящей кнопкой **Swap `[ ⇅ ]`**.

### 7. 📜 `feature-history` (История вычислений)
* Сохранение всех расчетов в локальную базу данных Room.
* Быстрая вставка из истории в калькулятор.
* Экспорт любого сохраненного расчета в PDF.

## 🏗️ Архитектура проекта (Multi-Module)

Проект строго следует принципам **Clean Architecture** и разделен на изолированные Gradle-модули:

```text
├── app                      # Точка входа, MainActivity, MainScreen (Таб-навигация), Onboarding
├── core-ui                  # Дизайн-система (Color, Theme, Type), компоненты (GlassCard, MathKeyboard, BounceClick), утилиты
├── core-math-engine         # Парсер выражений, математический солвер, шаги вычислений
├── core-domain              # Доменные модели (Formula, Variable, Element, CalculationResult)
├── core-data                # Room Database (CalculationEntity, Dao), DataRepository
├── feature-calculator       # Экран калькулятора, OCR сканер, BottomSheet шагов
├── feature-physics          # Формулы, симуляторы (маятник/баллистика), квизы
├── feature-chemistry        # Молярка, балансировщик, Менделеев, растворимость, атом
├── feature-geometry         # 2D солверы, 3D стереометрия с Canvas рендерером
├── feature-graphing         # Графопостроитель, анализ экстремумов
├── feature-converter        # Конвертер единиц
└── feature-history          # Экран истории и PDF экспорт
```

## 📌 Текущее состояние и последние обновления

* ✅ **Рефакторинг God-Objects:** Большие файлы (`PhysicsScreen`, `ChemistryScreen`) декомпозированы на независимые секции `< 200` строк.
* ✅ **Onboarding:** Внедрен 3-слайдовый приветственный экран (`OnboardingScreen`) с сохранением в `SharedPreferences`.
* ✅ **Системная интеграция:** Принудительный Dark Mode (`themes.xml`), защита от смещения верстки клавиатурой (`windowSoftInputMode="adjustNothing"`).
* ✅ **Чистые утилиты:** `ErrorLocalizer` (локализация ошибок) и `NumberFormatter` (US Locale, экспоненциальная запись для экстремальных величин).
* ✅ **100% готовность к компиляции:** Проект собирается без ошибок на JDK 21 / Android Gradle Plugin.

## 🤖 Инструкция для других AI-агентов и разработчиков

Если вы продолжаете разработку или анализируете данный проект:

1. **Не ломайте дизайн-систему:** Всегда используйте токены из `com.calculator.core.ui.theme.*` (`Background`, `SurfaceCard`, `SurfaceElevated`, `SurfaceBorder`, `TextPrimary`).
2. **Тактильность:** Оборачивайте кликабельные элементы в `.bounceClick { ... }` из `core-ui`.
3. **Числа и расчеты:** Для форматирования результатов используйте `com.calculator.core.ui.utils.NumberFormatter.formatResult()`.
4. **Размер файлов:** Не создавайте монолитных Composable-функций. Делите экраны на логические секции (`*Section.kt`).
5. **Zero-Scroll:** Сохраняйте адаптивную верстку без лишней вертикальной прокрутки на типовых смартфонах.
