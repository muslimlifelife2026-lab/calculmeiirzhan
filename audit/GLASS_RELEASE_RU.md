# AeroCalc: стекло, функции и проверка — 13 октября 2026

## Внедрено

- Оригинальный графитовый фон с серебряной волной. Стеклянные кнопки, карточки и навигация показывают соответствующий участок фона; текст остаётся резким. На Android 13+ применяется AGSL-рефракция края и размытие, на Android 12 — размытие, на Android 7–11 — прозрачный вариант без размытия. Ошибка шейдера отключает рефракцию на сессию и сохраняет размытие. Это собственная реализация по пользовательским референсам, а не системный Liquid Glass Apple; произвольные соседние элементы под стеклом не захватываются.
- Короткий системный тактильный отклик клавиш с учётом настроек устройства; подсветка следует месту касания. Индикатор нижней панели плавно движется, экраны сменяются с коротким переходом. Физические ощущения зависят от вибромотора телефона.
- Обучение сохранено: четыре урока и физический тренажёр. Добавлены восемь коротких вопросов, задача дня, проверка с объяснением, продолжение попытки и локальное сохранение прогресса. Неверный ответ не завершает задание. Дата учитывает локальный часовой пояс; Android API 24 поддерживается.
- Графики: готовый пример `a*x+b`, доступные ползунки параметров, выделение переменных через токены, округление шагов ползунка без ошибок Float. Параметры сохраняются при переходах между разделами.
- Физика: собственный опыт «Сила и движение», численные значения ускорения, координаты, скорости и кинетической энергии. Маятник использует согласованную модель малых углов с затуханием и корректную начальную скорость; баллистика использует реальное время без скрытого множителя 1,5. Условия идеализированных моделей указаны на экранах.
- Конвертер: десятичное вычисление BigDecimal/DECIMAL128, точные определения единиц, различение абсолютной температуры и ΔT, запрет температуры ниже абсолютного нуля. Добавлены сила, давление, энергия и время. Расчёт до 34 значащих цифр, показ до 14; это не обещание точности исходного измерения.
- Химия: 84 стандартных атомных веса по CIAAW 2024 с неопределённостями; массы отдельных изотопов остальных элементов обозначены отдельно. Отсутствующая электроотрицательность не заменяется нулём. Таблица растворимости по-прежнему неполная и честно обозначает отсутствующие данные.
- Реклама: постоянное место баннера без скачка высоты после загрузки. Межстраничная реклама подготовлена только после новых завершённых учебных заданий: 3 завершения и 3 минуты от запуска; затем минимум 5 минут и 3 новых завершения, максимум 2 показа за сессию. Отсутствующее объявление не задерживает пользователя. Повтор уже пройденного задания не вызывает рекламное событие.
- Инициализация рекламы перенесена после установки содержимого окна: при обычном запуске с сохранённой группой TEEN воспроизводился `Window couldn't find content container view`. После изменения обычный запуск успешен; отдельный тест проверяет старт и пересоздание MainActivity с сохранённой группой TEEN. Готовность SDK устанавливается только в callback завершённой инициализации.
- JVM-модули domain/math-engine используют Java 17, как Android-модули. Исправлена несовместимость class version 65/61, обнаруженная при запуске новых тестов графиков.

## До загрузки в Play

1. Дождаться активации нового **ключа загрузки** в Play Console с сертификатом `audit/upload_certificate.pem`. Ключ подписи приложения Google не заменять. Прежний закрытый тест уже использовал старый ключ; новый AAB не примут до активации нового сертификата.
2. Уточнить максимальный versionCode всех прежних загрузок. Сейчас `versionCode=2`, `versionName=1.1.0`; если максимум ≥2, увеличить код и пересобрать. Доступ к рабочей версии также должен быть одобрен Play.
3. Для межстраничной рекламы создать отдельный блок в AdMob и локально задать `ADMOB_INTERSTITIAL_UNIT_ID`. Сейчас release отключает этот формат при пустом ID; debug использует официальный тестовый блок. Реальный баннер настроен отдельно. Длительность и закрытие объявления определяет SDK; собственного принудительного таймера 10–15 секунд нет.
4. Проверить на физическом телефоне тактильность, масштаб шрифта, плавность, камеру, реальные показы AdMob и согласие UMP. Android 7–12 не проверялись на отдельном устройстве в этом прогоне. Эмулятор не подтверждает качество вибрации, FPS и расход энергии на целевых телефонах. Реальный межстраничный показ не проверен: собственного production ID ещё нет.
5. Декларации рекламы, аудитории и данных в Play Console должны соответствовать сборке и фактическому использованию SDK. Перед релизом необходимо повторное тестирование обновлённой версии: прежний бета-тест не проверял эти изменения.

Полноценный CAS, свободные 3D-построения, редактор молекул, лаборатория датчиков и продуктовая аналитика сейчас не реализованы. Восемь учебных заданий — стартовый набор.
